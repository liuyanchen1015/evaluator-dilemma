# The Evaluator Dilemma

Static pages for the blog post *The Evaluator Dilemma: Does Recursive Self-Improvement Really Improve?* and its companion audit registry.

- Blog: https://liuyanchen1015.github.io/evaluator-dilemma/
- Audit registry: https://liuyanchen1015.github.io/evaluator-dilemma/registry/

The pages are generated from their sources by `deploy.py`; edit the sources, run `python3 deploy.py`, and commit the result.

The tab icon is `favicon.ico` next to the pages, so each host can serve its own: this repository has the squirrel from the homepage, and the CSAIL copy uses the CSAIL logo.
